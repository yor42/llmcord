## Writing rules

- Say "server", never "guild", in anything a user reads.
- Name the kind: "world", "hub" or "world or hub". Use "space" only where a command already uses it.
- Say "lorebook", not "book", except in a short list where the context is clear.
- Deletion dialogs use the same shape: the title "Delete *name*?", what is removed and what stays, then **Cancel** and a red **Delete …** button.

## Korean (`ko`)

Approved by the user on 2026-10-12 (FEAT-46, decision D).

- Use the polite 해요체 everywhere: `저장했어요.`, `다시 시도해 주세요.` Buttons are short nouns or verbs: `저장`, `삭제`, `취소`, `변경 사항 저장`.
- Use the Korean column above. Game words are the ones Korean players use (히트, 스탠드, 더블다운, 스플릿, 폴드, 체크, 콜, 레이즈, 올인; hands 하이카드 … 로열 플러시), and a player's turn is `차례`.
- Write I Doubt It as `다우트 (카드게임)` where the name stands alone (titles, pickers, game lists) and plain `다우트` inside a sentence, so particles attach to 트 (`다우트가`). The doubt button is `다우트!`.
- After a placeholder, write the particle pair in the format spec (`{name:이/가}`, `{world:을/를}`, `{place:으로/로}`); the bot picks the right one. Put counters in the text (`{count}장`, `{count}명`) and use digits, not number words.
- Never translate what people typed, character lines, command and option names, or code names.
